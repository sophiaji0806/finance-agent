第 5 步：术语词典（大白话）

按"你大概会先遇到哪个"排序。每个术语回答三件事：是什么 / 要不要花钱 / 为什么能直接用。

Python —— 一种编程语言，也是你电脑上的一个程序。你写的 .py 文件就是"用 Python 说的话"，python 文件名 命令让电脑照着做。免费开源，已装好。
包 / 库 / 依赖（library / package / dependency） —— 别人写好的、打包好的代码，你 import 一下就能用，不用自己从头写。比如 requests 帮你发网络请求，fastapi 帮你搭网站。pip 负责下载它们。绝大多数免费开源。
import —— "把这个库拿过来用"。import requests = 我要用 requests 这个库的功能。类比：从工具箱里拿出扳手。
函数（function） —— 一段起好名字、可反复调用的代码。就像菜谱里的一道菜："给函数 3 个数字，它算出 1 个结果"。gross_margin(收入, 成本) 进去两个数，出来一个毛利率。你调它就行，不用重写算法。
模块（module） —— 一个 .py 文件就是一个模块。app.tools.db 指 app/tools/db.py 这个文件。点号 = 文件夹层级。
API —— 一个程序给另一个程序"下单"的接口。类比：餐厅菜单。你按菜单点菜（发请求），后厨做菜（处理），端上来（返回结果）。
API key —— 调用某个收费 API 时用的"钥匙/账号密码"。DeepSeek 的 API 按使用量收钱，key 用来证明"是你本人在用、钱记你账上"。所以 key 要保密，不能发到网上。
LLM（大语言模型） —— Large Language Model。就是 ChatGPT、DeepSeek 这类"会聊天、会推理"的 AI 模型。它是个在线服务，你发文字过去，它回文字过来。要联网、要 key、要花钱。
DeepSeek —— 一个国产 LLM，有 API 服务。这个项目调它当"大脑"。选它因为便宜、有中文能力。
Function Calling（函数调用 / 工具调用） —— 一种让 LLM 不只聊天、还能"喊你帮忙做事"的技术。你告诉模型"我有这些工具"，模型会回"我要调用 query_db 这个工具，参数是…"。你的 Python 代码去执行，把结果塞回给模型。这就是整个 Agent 的核心。
Agent（智能体） —— 一个"能自己决定下一步做什么"的程序。普通程序：你让它算 A 它算 A。Agent：你给它一个目标，它自己判断"先查库、再算指标、再查准则"，一步步来。本项目 = 一个财务 Agent。
RAG（检索增强生成） —— Retrieval-Augmented Generation。让模型回答时先查资料再回答，而不是瞎编。流程：从知识库里搜出最相关的几段文字 → 拼进提示词 → 让模型照着资料回答。本项目用 TF-IDF 做"搜"这步。
TF-IDF —— 一个"文字找相似"的算法，几十年前就有的经典方法，公开、免费、不是某个公司的产品。思路：一篇文字里出现多的词 = 重要（TF），但太常见的词（"的""了"）= 不重要（IDF），两者相乘给每个词一个权重，再把两段文字变成两串数字，比较数字的夹角（余弦相似度）就知道像不像。为什么能直接用？因为 rag.py 里自己用 Python 实现了这几十行，不依赖任何公司、不联网、不花钱。
余弦相似度（cosine similarity） —— 比较"两个向量方向有多接近"的方法，值在 0~1，越接近 1 越像。这里用来判断"问题"和"哪段知识"最相关。
向量 / 向量化（vector / embedding） —— 把一段文字变成一串数字。TF-IDF 是一种"变数字"的办法（不用模型）；更高级的是用 embedding 模型变。本项目选 TF-IDF 因为 DeepSeek 没有 embedding 接口。
SQL —— Structured Query Language，跟数据库说话的"查询语言"。 SELECT * FROM companies = "把 companies 表所有列给我"。像用固定句式向账本提问。
数据库（database） —— 专门存数据、能快速查询的东西。类比：一个结构化的账本/表格。
SQLite —— 一种轻量数据库，整个数据库就是磁盘上一个文件（本项目就是 data/finance.db）。不用装服务器，Python 自带支持，所以免费、离线、直接用。
表（table） —— 数据库里的一张表格。本项目两张表：companies（公司信息）、financials（财务数字）。
FastAPI —— 一个 Python 库，用来快速搭"网站后端接口"。它把你的 Python 函数变成一个网址，别人访问这个网址就触发函数。@app.get("/health") = 访问 /health 就执行下面那个函数。免费开源。
uvicorn —— 一个"服务器"程序，负责真的把 FastAPI 写好的网站跑起来、接收外面的访问。免费开源。
pytest —— 一个"自动检查"的库。你写几个"正确答案应该是 X"的断言，pytest 帮你一个个跑，看代码对不对。本项目的 tests/ 里就写了公式的检查。
Docker —— 把整个项目打包进一个"集装箱"，到任何电脑上都能原样运行，不用管那台电脑装没装 Python。类比：把菜连同锅碗都打包，端到哪都能吃。
GitHub Actions / CI —— 每次你改完代码推到 GitHub，它自动帮你在云端跑一遍测试，告诉你有没有改坏。CI = 持续集成（自动测试）。
JSON —— 一种"存数据"的文本格式，键值对，人和机器都能读。{"name":"深圳云科技","code":"300001"}。本项目的数据文件、工具参数都用它。
JSON Schema —— 用来"描述一个 JSON 长什么样"的规范。Function Calling 里用它告诉模型"这个工具要哪些参数、参数是什么类型"。
.env 文件 / 环境变量 —— 放"敏感配置"的文件（比如 key），不让它写死在代码里。好处：换 key 不用改代码，也不会把 key 传到网上。
开源（open source） —— 代码公开、任何人都能免费看、免费用的东西。Python、fastapi、SQLite、pytest、TF-IDF 算法全部开源。这正是"能直接用"的原因。
子进程（subprocess） —— 让程序"开一个新的独立小进程"去跑一段代码，跑完再把结果还回来。好处：那段代码出错或死循环，不会把主程序拖垮。
超时（timeout） —— 限制"最多等多久"。超过时间就强制停止，防止程序卡死永远不动。

def seed(force=False):           # 建表 + 塞示例数据
    c.executescript("CREATE TABLE companies(...)")  # 建"公司"表

def query(sql, limit=50):       # 执行只读查询
    s = sql.strip().lower()         # 去掉空格、变小写
    if not (s.startswith("select") or s.startswith("with")):

    cur = conn.execute(sql ... LIMIT 50)   # 执行 + 强制最多 50 行
    return [dict(zip(cols, row)) for row in cur.fetchall()]  # 结果转成字典列表

6.5 app/tools/financial_models.py —— 财务公式

def gross_margin(revenue, cogs):   # 毛利率函数
    if revenue == 0: return 0.0          # 收入为 0，除不了，直接返回 0（防崩）
    return (revenue - cogs) / revenue # 毛利率 = (收入-成本)/收入

def wacc(equity, debt, cost_equity, cost_debt, tax_rate):
    total = equity + debt          # 总资本 = 权益 + 债务
    we, wd = equity/total, debt/total   # 各自权重
    return we*cost_equity + wd*cost_debt*(1-tax_rate)  # 加权平均资本成本

def expected_loss(pd, lgd, ead):  # 预期信用损失 ECL
    return pd * lgd * ead          # 违约概率 × 损失率 × 敞口

def irr(cashflows, guess=0.1):     # 内部收益率，牛顿迭代
    r = guess                       # 从 10% 开始猜
    for _ in range(100):              # 最多迭代 100 次
        v = _npv(r, cashflows)      # 算当前净现值 NPV
        dv = derivative(r)          # 算 NPV 的斜率(导数)
        nxt = r - v/dv              # 牛顿步：沿切线逼近根
        if abs(nxt - r) < 1e-9: return nxt  # 足够近，返回结果
        r = nxt
